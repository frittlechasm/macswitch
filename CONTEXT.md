# Context

## Glossary

### Mac Workspace Switcher

A keyboard-driven macOS overlay for moving focus between visible work items.

### Workspace

The currently active macOS Space/Desktop.

### Window Candidate

A selectable top-level window that can receive focus from the Mac Workspace Switcher.

### Application Group

The set of Window Candidates owned by the same running application.

### Switcher Session

The short-lived interaction that starts when the switcher hotkey is pressed and ends when the user selects a Window Candidate or cancels.

### Switcher Shortcut

The keyboard input that starts or advances a Switcher Session.
